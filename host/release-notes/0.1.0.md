First release of the optional login helpers for the [openconnect-ocproxy](https://github.com/matteosecli/openconnect-ocproxy) container. They run on the host, check the container every minute, and show a desktop notification when a login is needed or the session expires within 15 minutes. Clicking the notification opens `docker exec -it openconnect-ocproxy vpn-login` in a new terminal window. The helpers store no credentials.

These are 0.x releases: settings and behavior may still change between versions. The helpers are versioned separately from the container image, which is published on [GHCR](https://github.com/matteosecli/openconnect-ocproxy/pkgs/container/openconnect-ocproxy). They work with image 2.2.0 and later. 2.3.0 is recommended: a login abandoned at its prompt (for example, the terminal was closed) no longer blocks later logins.

### macOS: `openconnect-ocproxy-helper-0.1.0-macos.zip`

Unzip and open **OpenConnect Proxy Login.app**, then add it under System Settings → General → Login Items to start it automatically. The app is not signed with an Apple developer certificate, so macOS refuses to open it the first time; allow it under System Settings → Privacy & Security → *Open Anyway*. To avoid that, build it yourself from a checkout with `sh host/macos/build.sh`. Works with Terminal and iTerm2.

### Linux: `openconnect-ocproxy-helper-0.1.0-linux.tar.gz`

```bash
tar xzf openconnect-ocproxy-helper-0.1.0-linux.tar.gz
sh openconnect-ocproxy-helper-0.1.0-linux/linux/install.sh
```

Installs a systemd user service under `~/.local`. It needs a desktop notification server with action support (GNOME, KDE Plasma and most others), plus `gdbus`, `dbus-monitor` and `stdbuf`. Tested on Ubuntu 26.04 (GNOME) with Ptyxis and GNOME Terminal.

See the [README](https://github.com/matteosecli/openconnect-ocproxy#macos-login-helper-optional) for settings and details. Check the downloads against `SHA256SUMS` with `shasum -a 256 -c SHA256SUMS` (macOS) or `sha256sum -c SHA256SUMS` (Linux).
